# 方舆经纬 · 读史方舆纪要

[![CI](https://github.com/V-T-V/fangyu-jingwei/actions/workflows/ci.yml/badge.svg)](https://github.com/V-T-V/fangyu-jingwei/actions/workflows/ci.yml)

《读史方舆纪要》（顾祖禹，130 卷）全书舆图可视化。数据自国学导航分卷文本真实解析。

## 打开

双击 `启动方舆经纬.bat`（起本地服务并自动开页），或直接双击 `index.html`（底图瓦片需联网）。或本地服务：

```
python -m http.server 8613
# http://127.0.0.1:8613/index.html
```

深链 `#search=坚壁清野` 可直达一次检索（填入并展开结果）。

其余深链（选中状态自动写回 URL，刷新/分享保持）：
- `#mode=舆图&p=huguang&fu=武昌府` —— 省 + 府详情
- `#mode=形势&era=8` —— 历代州域形势（0~8 = 卷一~卷九）
- `#mode=川渎&r=大江` —— 水道

**漫步模式**：底栏 **⚑ 漫步**——一键随机穿越帝国：随机省→府→原文段落，每次点击都是一段未曾谋面的方舆。

快捷键：`Esc` 收起面板 · 形势模式 `←`/`→` 或底部九卷时间轴翻卷 · 检索框回车直达首条。原文可「⤓ 文本」存为本地 .txt，或 Ctrl+P 打印/存 PDF（专用打印版式）。「☾」夜读墨色主题（localStorage 记忆）；「🔊」朗读（TTS，自当前视口段落起读、逐段高亮跟随，⏹ 停止）。按 `?` 唤出关于·校勘记。

**阅原卷全文**：府/省序/形势卷/川渎卷面板均有「阅原卷全文」入口。全文按省懒加载（`data/text/*.js`，首屏不含），编码损坏句以淡显点线标注。

**全书全文检索**：顶栏检索任意词句（如「坚壁清野」）→ 名录结果底部点「📖 在全书原文中检索」→ 按需加载 260 万字原文并扫描 → 片段预览列表（按命中数排序）→ 点击直达该篇原文，命中词常驻朱底标记并居中定位。

**原文交叉链接**：正文中所有府/州名（含裸名如"荆州"）与县名全称（"华容县"）均可点击，直达该府舆图与详情；同名异地按"当前省优先"消歧。字号 A−/A+ 可调。府原文顶部有「卷内跳转」（附郭/属州/县 chips，直达该县段落）。

**书签与续读**：府详情点「☆ 书签」收藏（localStorage 持久化，上限 30，总叙面板可管理/删除）；阅读任意全文自动记录，总叙面板「⟳ 续读」一键回到上次篇章。

**地名古今对照表**：总叙纲目或底栏「古今对照」进入——双页签「府州 380 / 县 1104」明今对照（名/类/省/附郭或隶属/治今/卷），行点击入府；可导出 CSV（带 BOM，Excel 直开）、**KML**（Google Earth 原生）或 **GeoJSON**（1473 个治所点位：府/州整编坐标 + 县推算坐标，属性含省/隶属/依据，QGIS/Google Earth 直开）。

**形势事件定位**：大事年表 29 条可定位事件（牧野、赤壁、淝水、澶渊、厓山、土木……）带 ➤ 角标，点击地图飞临该地并绽放朱圈涟漪。

**疆域示意**：形势模式以本卷所载都邑实时生成凸包外扩的淡朱晕罩+朱砂虚线轮廓（非考证边界，面板有说明）；都城标签方向交替避让。另支持 prefers-reduced-motion 减少动效。

**卷首文献**：总叙面板（展卷首屏）列魏禧叙/彭士望叙/总叙三篇/凡例二十六则/州域形势纪要序，点击即读；亦纳入全文检索范围（如搜「乡导」总叙三 11 处居首）。

**九边防线与关隘**：50 处关隘（含九边重镇加粗）zoom≥4 朱三角显现，朱砂虚线自嘉峪关串至山海关；悬停示名/类型/所属府/今地。`data/passes.json` 可扩充。

**量距工具**：地图上 **Shift+点击两点**，即得直线公里数与折合明里（按本站标定的驿路系数 0.62，1 明里≈0.357 直线公里），可当场验证原书"府东七十里"等里程记载。

**府域晕与领属线**：选中一府，三层同时呈现——县治凸包轮廓、府→县虚线辐射、县治点。

**省疆域晕**：舆图选中一省即显其治所凸包晕罩（省色虚线+淡晕，与形势朱晕同一语言），点空白取消即隐。河线以控制点+Chaikin 切角平滑渲染（大江 34 点/大河 28 点沿真实走向）。

**县治推算层**：zoom≥7 显现 1096 个县治——由原书「县名·府方位N里」三角化推算。悬停示县名·隶府·方位里程·定位类型；**点击打开县级信息卡**（统计 + 原文段首）；zoom≥8 县名常显（碰撞避让）；检索直达县卡。附郭县朱砂空心方框。方位里程皆出原书，属方法近似。

**属州层**：舆图模式放大至 6 级及以上，187 枚属州小方章（8px 空心、同省色）在府印间浮现，悬停示"隶某府·今某地"，点击直达所属府详情（坐标为人工整编，土州为近似）。

**川渎沿流要邑**：七水（含海道·元明海运故道）标注 50 处沿流重镇（岷山江源、夔峡、金陵、云梯关……），点要邑直达其府。舆图模式点地图空白处取消省选。

**文本校勘约定**：源本编码损坏句淡显点线标注，句内半角/全角拉丁与假名字符一律以 □ 缺字符代之（全半角均检）。

## 离线可用（PWA）

`sw.js` 三级缓存——整本书装进口袋：

- **外壳预存**：index / css / js / 数据文件，首访后秒开（21 项）
- **全文懒存**：读过哪卷存哪卷；做过一次全书检索 = 260 万字全部离线
- **瓦片限额存**：已览底图瓦片 stale-while-revalidate，上限 1200 张防膨胀
- 页面导航网络优先、离线回退缓存外壳；右下角 **◼ 离线可用** 徽标实时感知
- manifest + PNG 图标（192/512/maskable），支持"安装应用"
- `file://` 直开自动跳过 SW，兼容如故

## 文心 · 全书文本计量

底栏 **🖋 文心** → 顾祖禹笔墨去向的三个追问（首开自动载入全书原文并计量，此后缓存秒开）：

- **卷帙分布**：十五省方舆各自多少万字——笔墨轻重即是详略判断
- **府名被引 TOP 20**：192 个府级地名在 260 万字中被掂量的次数（点行直达全书检索）；
  以简名计（去「府／州／卫」尾），单字简名与省名撞车者退回全名（如「河南府」），
  同名词目（如「太平」）为合计
- **战略词汇分省浓淡**：形胜／险要／要害／咽喉／锁钥／屯戍／烽堠… 16 词，
  每万字密度的省际排序——边镇语汇与腹里语汇之差即明代国防地理心图
- **文→地联动**：任何省名一点即入舆图观其省域；府行 ➤ 直飞该府——以文证地，以地证文
- **被引着色**：「🗺 被引着色」把 192 府的掂量次数画上舆图——
  圆径与色温（赭→朱）随 log(次数) 缩放，附色标图例；
  点圆入该府。顾祖禹的战略注意力分布一图可览
- **CSV 导出**：省卷字数 + 16 词 × 15 省计数 + 192 府被引全量

## 底图切换

切到影像看的是**真山川**——太行陉道、黄河故道、三峡天险的地形肌理，
配合暖色绢纱罩与印章光环增强，绢本气质不丢；瓦片同样经 Service Worker
缓存（离线可看已览区域），断供自动回退绢底。

（几何探针验证零重叠）。

## 三维形胜（与 2D 平行）

底栏 **⛰ 形胜** → `3d.html`（MapLibre GL + Esri 影像 + AWS 高程）：

- **真山川**：太行、三峡、河套的地形起伏可见可感（夸张 1.4）
- **▶ 飞览九边**：镜头贴地形自嘉峪关飞至山海关，11 站关隘点名
- **形胜视角**：居庸望京师 / 潼关望河曲 / 剑门窥蜀 / 山海关观海 / 井陉出太行……
  立在关口，以顾祖禹之眼观之（顶栏下拉）
- **被引文柱**（◧ 开关）：192 府全书掂量次数 → 朱色列林高度（示意尺度），
  顾祖禹的战略注意力天际线
- **晓雾山影 + 江河流光**：DEM 山影叠加、大江虚线相位流动（8fps）
- **开场长镜头**：自西域疾掠而至晋陕黄河大峡谷（拖动即断）
- 府印/文柱/关隘皆可点（卡内「入 2D 详卷」深链）；Ctrl+拖拽俯仰，右键旋转
- 性能：全部标记 GPU 化（零 DOM 标记）、antialias、requestRenderMode 按需渲染
- **山河九朝**（左下控制条）：拖动时间轴或在九朝间自动推演——疆域低墙 +
  王都擎柱（80km）+ 要邑墨柱立于真山河之上，唐虞三代 → 明
- **九朝旁白**（🔊）：自动推演时诵读朝代纪年与首二大事；点朝代名开朝代卡，
  「入 2D 形势卷」深链直达原文全文
- WebGL 缺失优雅降级；高程不可达自动平面 + 提示；方案详见 [DESIGN_3D.md](DESIGN_3D.md)
