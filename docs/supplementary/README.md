# 配套数据说明（Supplementary Materials）

《读史方舆纪要》的空间与文本计量研究——三份数据表，与论文正文（ANALYSIS.md / PDF）**逐位一致**。

## S1_provincial_metrics.csv

十五省全量度量（13 列 × 15 行，UTF-8-BOM，Excel 中文直开）。

| 列 | 含义 | 口径 |
|---|---|---|
| 省 | 十五布政使司 | — |
| 字数 | 站点语料字符数（xu + fu 全文） | `data/text/*.js` 纯文本提取 |
| 16词合计 | 军事语汇总频次 | 16 词表见论文 §2.4 |
| 语汇密度/万字 | 16词合计 × 10000 ÷ 字数 | 消除卷帙规模影响 |
| 14动词合计 | 攻守动词总频次 | 14 词表见论文 §4.8 |
| 动词密度/万字 | 同上归一化 | — |
| 16水名合计 | 具名水提及总频次 | 16 水名表见论文 §4.7 |
| 水名密度/万字 | 同上归一化 | — |
| 12山名合计 | 具名山提及总频次 | 12 山名表见论文 §4.7 |
| 山名密度/万字 | 同上归一化 | — |
| 192府被引合计 | 该省全部府名全书被引次数之和 | 简名计法（§2.3） |
| 府数 | 该省府级政区数 | `data/site_data.js` |
| 判断词(谓+盖)密度/万字 | 学术判断动词归一化密度（§4.14） | 纯语料提取 |

## 复现方法

```bash
# 全部分省度量（含引书榜、时代层、山河密度、城周、动词）
node paper_stats.js

# 府名被引次数
python build_mentions.py

# 本三表的生成
# S1: paper_stats.js 同源提取（node 纯语料，非 JS 裸切片）
# S2: build_mentions.py 输出
# S3: paper_stats.js 《》正则
```

**口径声明**：一切数字出自站点语料（`data/text/*.js`，xu + fu 全文纯文本），不含 JS 对象键名。口径纪律见论文 §2.5。
