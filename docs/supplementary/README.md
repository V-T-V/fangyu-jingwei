## 复现方法

```bash
# 全部分省度量（含引书榜、时代层、山河密度、城周、动词）
node paper_stats.js

# 府名被引次数
python build_mentions.py

# 本三表的生成
# S1: paper_stats.js 同源提取（node 纯语料，非 JS 裸切片）
# S2: build_mentions.py 输出
# S3: paper_stats.js 《》正则
```

**口径声明**：一切数字出自站点语料（`data/text/*.js`，xu + fu 全文纯文本），不含 JS 对象键名。口径纪律见论文 §2.5。

## S5_county_distances.csv

县治距府治直线距离全量底账（n=962，论文 §三 表 1 之源；`python tools/build_s5.py` 再生）。

| 列 | 含义 | 口径 |
|---|---|---|
| 省/府/县 | 政区名 | `data/site_data.js`（基名） |
| 直线km | 县治→府治大圆直线 | 平面近似（纬度校正） |
| 原书方位 | 《纪要》「县名·府/州方位」句式 | 原文 |
| 原书里程(里) | 同句式里程 | 中文数字解析 |

中位 53.86 km ≈ 论文 53.9（排序位置差所致，同一分布）。
