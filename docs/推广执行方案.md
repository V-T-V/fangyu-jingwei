# 方舆经纬 · 推广执行方案

> 目标：从「零用户」到「被引用」的三个月路线图

---

## 现状诊断

| 有 | 没有 |
|---|---|
| 完整可用的在线平台 | 一个真实用户 |
| 十八层数字分析 | 一篇经过同行评审的论文 |
| 精美的绢本视觉设计 | 一条英文界面 |
| 完整的开源代码 + CI | 一个选定的开源许可 |
| 配套数据 S1-S4 | 一个引用我们的学者 |

**核心矛盾**：产品完成度 85%，市场触达度 0%。

---

## 第一阶段 · 基础补全（第 1-2 周）

**目标**：消灭推广前的最后障碍

### 1.1 选定许可（阻塞项）
- **推荐 CC BY-NC-SA 4.0**（学术常用·非商业·同名共享）
- 写入 LICENSE 文件 + CITATION.cff
- 预计工时：5 分钟

### 1.2 加装分析
- 部署 [Umami](https://umami.is)（自托管·无 Cookie·GDPR 友好）或 [Plausible](https://plausible.io)
- 追踪：PV / UV / 停留时长 / 热门功能 / 地域
- 埋点：`透视打开` `文心打开` `3D打开` `全文检索` `GeoJSON导出`
- 预计工时：半天

### 1.4 论文投稿准备
- 补文献综述（20 篇《读史方舆纪要》研究，重点：谭其骧·侯仁之·辛德勇）
- 联系 1-2 位历史地理学者做非正式审读
- 目标期刊：《历史地理》·《中国历史地理论丛》·《数字人文研究》
- 预计工时：1-2 周

## 第二阶段 · 种子用户（第 3-4 周）

**目标**：10-30 个真实用户 + 第一批反馈

### 2.1 学术圈精准推送

| 渠道 | 具体动作 | 预期 |
|---|---|---|
| 历史地理学界微信群 | 发一条 200 字介绍 + 链接 + 截图 | 5-10 次访问 |
| 豆瓣「历史地理」小组 | 发帖：标题「做了一个《读史方舆纪要》的交互地图」 | 20-50 次点击 |
| 知乎 | 回答「如何入门历史地理」类问题，附链接 | 50-100 次点击 |
| 微信公众号（如有） | 发文《260 万字古文如何变成一张地图》 | 视粉丝量 |

### 2.2 数字人文社区

| 渠道 | 具体动作 | 预期 |
|---|---|---|
| 数字人文研究网 (dhcn.cn) | 发布项目介绍 | 10-20 次点击 |
| GitHub Trending | 如果 star > 50 可上榜 | 持续流量 |

### 2.3 反馈收集
- 在首页加一个「反馈」按钮（mailto 或 Google Form）
- 目标：收集 5 条真实反馈
- 关注：哪些功能被使用 / 哪些被忽略 / 什么让用户困惑

## 第三阶段 · 内容营销（第 5-8 周）

**目标**：建立「方舆经纬 = 读史方舆纪要数字化」的心智

### 3.1 核心内容矩阵

| 内容 | 形式 | 发布渠道 | 目的 |
|---|---|---|---|
| 「山东为什么是全书最特殊的一省」 | 短文 + 四色地图截图 | 知乎 / 微信 | 展示发现深度 |
| 「顾祖禹的书架」 | 长文 + 榜单图 | 豆瓣 / 公众号 | 展示文本计量 |
| 「武昌—襄阳：天下第一战略对」 | 短视频 / 动图 | B 站 / 抖音 | 视觉冲击 |
| 「三维看太行山」 | 3D 录屏 30 秒 | B 站 / 视频号 | 展示 3D 能力 |
| 「一日可达：明代县治的空间密码」 | 数据可视化长图 | 知乎 / Twitter | 学术传播 |

### 3.2 关键指标

| 指标 | 4 周目标 | 8 周目标 |
|---|---|---|
| 独立访客 | 100 | 500 |
| GitHub Star | 20 | 100 |
| 论文引用 | 0 | 1（自引不算） |

## 第五阶段 · 可持续运营（第 3 月后）

### 5.1 降低维护成本
- CI 全自动（已实现）
- Lint + pre-commit 防止退化（已实现）
- 唯一需要人工的：回复 issue / 合并 PR / 数据更新

### 5.2 内容节奏
- 每月 1 篇深度发现文章
- 每周 1 条数据可视化推文
- 每季度 1 次功能更新

### 5.3 合作可能
| 对象 | 合作形式 | 价值 |

## 风险与对策

| 风险 | 概率 | 对策 |
|---|---|---|
| 学者指出「发现」是领域常识 | **高** | 诚实回应·强调方法新颖性而非结论首创性 |
| 坐标精度被质疑 | 高 | 承认局限·开放数据供验证·邀请合作改进 |
| 无人问津 | 中 | 调整内容策略·从视觉冲击切入而非学术深度 |
| 服务器/域名成本 | 低 | GitHub Pages 免费·无自建服务器 |
| 数据版权争议 | 低 | 文本来自国学导航公开页面·注明出处 |
