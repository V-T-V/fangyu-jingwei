# 方舆经纬 · B 站 60 秒视频脚本

> 目标：一个从未听说过这个项目的人，看完 60 秒后想去点链接。

## 前 5 秒（钩子）

**画面**：3D 地形上太行山的陡崖，镜头从华北平原仰视

**旁白**：
> 三百年前，一个人用二十余年写了一百三十卷书，讲遍了中国的每一座山、每一条河。

**字幕**：260 万字 · 1489 个地点 · 130 卷

## 5-15 秒（展示规模）

**画面**：快速截图切换——2D 地图上 193 个府治印章亮起 → 县治点密布 → 九边防线横贯

**旁白**：
> 我们把这 260 万字变成了一个交互地图——每一个府、每一个县、每一座关隘，都可以点击。

**字幕**：点击探索 · 1489 治所 · 全文检索

## 15-30 秒（展示文心）

**画面**：文心面板打开，四色密度着色切换——语汇（青）→ 动词（赭），河南和广东的颜色反转

**旁白**：
> 更厉害的是，我们可以用计算机分析他的写作模式——他写北方用战争叙事，写南方用设防警告。

**字幕**：北方写史 · 南方设论 · 二十一层发现

## 30-45 秒（高潮：山东）

**画面**：密度着色停在山东（孤立色块），镜头推近

**旁白**：
> 但最特殊的，是山东。五种统计方法都说它反常——因为黄河、运河、海防三线交汇，逼出了作者最高强度的分析推理。

**字幕**：山东 = 认知孤岛 · 判断密度全省第一

## 45-55 秒（3D 演示）

**画面**：3D 模式开启，飞览九边——从嘉峪关飞到山海关，地形起伏

**旁白**：
> 还有三维模式——在真实地形上飞越九边防线，立在潼关看黄河转弯。

**字幕**：3D 形胜 · 真地形 · 九边飞览

## 最后 5 秒（号召）

**画面**：绢底方印 logo + URL

**旁白**：
> 方舆经纬——用二十一世纪的工具，读十七世纪的地理。

**字幕**：
> 🔗 v-t-v.github.io/fangyu-jingwei
> 免费开源 · 无需安装

## 制作说明

| 项 | 建议 |
|---|---|
| 总时长 | 55-65 秒 |
| 配音 | 低沉男声 / 沉稳女声（不要用 AI 合成的机械感） |
| BGM | 古琴或箫，低调，不抢旁白 |
| 剪辑节奏 | 前 15 秒每 2 秒切一个画面，之后放缓 |
| 字幕 | 始终有，用楷体或宋体，白色黑边 |
| 封面 | 3D 太行山截图 + 标题「260 万字古文变成一张地图」 |

## 素材清单

| 素材 | 来源 | 备注 |
|---|---|---|
| 3D 太行山 | 3d.html 选「井陉出太行」+ 录屏 | 需要 DEM 成功加载 |
| 2D 府治印章 | index.html 默认视图 + 录屏 | 展示点击交互 |
| 密度着色反转 | 文心 → 密度着色 → 切换语汇/动词 | 最有视觉冲击力的 5 秒 |
| 九边飞览 | 3d.html → ▶ 飞览九边 | 需要 11 个停靠点都过一遍（约 50 秒，可加速） |
| Logo | icons/icon-512.png | 最后定格 |
