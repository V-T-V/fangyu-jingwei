# 三维看太行：顾祖禹说的「天下之脊」长什么样

> 顾祖禹在《读史方舆纪要》中把太行山称为「天下之脊」。但你不看三维地形，就永远不知道这四个字有多准确。

**在线体验 → [方舆经纬 · 三维形胜](https://v-t-v.github.io/fangyu-jingwei/3d.html)（顶栏下拉选「井陉出太行」）**

## 太行山在书中有多重要

先看数字：在全书 260 万字中，「太行」被提及 **225 次**——是第二名（荆山 74 次）的 **3 倍**。

在「天下之X」的意象统计中，「天下之脊」出现 4 次，指的是太行山——它像一根脊椎骨，纵贯华北平原西侧，从北京一直延伸到黄河岸边。

但二维地图上，太行山只是一条褶皱。你必须看三维地形才能理解它为什么是「脊」。

## 三维视角下的太行

打开方舆经纬的三维模式，选「井陉出太行」视角。你会看到：

1. **西侧**：黄土高原，海拔 1000-1500 米，起伏平缓
2. **东侧**：华北平原，海拔 50-100 米，一马平川
3. **中间**：太行山体，像一堵 **从天而降的墙**，东侧是陡崖，西侧是缓坡

这就是「脊」的含义——**不对称**。从西边上山是缓坡，可以骑马；从东边看是绝壁，必须走峡谷。

## 八陉：墙上的门

太行山这堵墙上开了八个口子，叫「太行八陉」。它们是穿越太行山的唯一通道：

| 陉名 | 今地 | 书中提及 |
|---|---|---|
| **井陉** | 河北井陉 | 直接提及 + 关隘条目 |
| 滏口 | 河北磁县 | 沿途要塞 |
| 白陉 | 河南辉县 | 少提及 |
| **轵关** | 河南济源 | 设关防守 |
| 太行陉 | 河南沁阳 | 天井关所在 |
| 飞狐口 | 河北蔚县 | 飞狐口条目 |
| 蒲阴陉 | 河北易县 | 紫荆关所在 |
| 军都陉 | 北京昌平 | 居庸关所在 |

在三维地形上，你能清楚地看到这些「陉」就是山体上的深切峡谷——河流千万年切割出来的天然走廊。每一条陉的出口处，几乎都设有一座关隘（居庸关、紫荆关、井陉关……）。

## 为什么太行是「天下之脊」

顾祖禹的逻辑：

1. **太行之东**是华北平原 → 得平原者得人口与粮仓
2. **太行之西**是黄土高原 → 得高原者得骑兵与地势
3. **谁控制了太行八陉，谁就控制了东西之间的通道**
4. **控制了通道，就控制了华北的命运**

历史上：
- **韩信**背水一战在井陉 → 灭赵
- **曹操**越太行征高干 → 定并州
- **刘福通**红巾军北伐走太行 → 撼动元朝
- **土木堡之变**后瓦剌从飞狐口入 → 明廷震动

每一次，太行山都是**决定性的地理变量**。

## 在线体验指南

打开 [三维形胜](https://v-t-v.github.io/fangyu-jingwei/3d.html)：

1. **等 3-5 秒**——高程数据在后台装载（如果失败会提示，点击可重试）
2. 顶栏下拉选「**井陉出太行**」——镜头会飞到太行山中段，以 76° 俯角朝东看
3. 你会看到：**眼前的陡崖是太行东坡，远处的平地是华北平原**
4. 用 **Ctrl+拖拽** 旋转视角，**右键拖拽**改变俯仰
5. 试试「居庸望京师」——从居庸关向南看北京平原
6. 试试「潼关望河曲」——看黄河在潼关的直角转弯

**如果地形加载失败**（网络原因），可以切换到影像模式——虽然没有高度，但卫星影像上的太行山山脊线依然壮观。
